Why Liquid Glass

Built different.

Not just CSS tricks. Real physics, real depth, real beauty.

01
Real Refraction
Backdrop filters, inner shadows, and highlight layers simulate actual glass optics — not flat translucency.
02
Iridescent Color
Animated gradient backgrounds shift in hue as you interact, mimicking thin-film light interference.
03
Spring Physics
Every transition uses cubic-bezier spring curves for that satisfying over-shoot-and-settle feel.
04
Zero Dependencies
Pure CSS & vanilla JS. No frameworks, no bloat. Drop it in any stack and it just works.
05
Dark & Light
Every component adapts to both themes automatically via CSS custom properties.
06
Fully Accessible
WCAG 2.1 AA compliant contrast ratios. Focus states. Keyboard navigable. Screen reader friendly.
