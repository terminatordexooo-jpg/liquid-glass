Why Liquid Glass

Built
different.

Not CSS tricks. Real physics, real depth, real beauty. Every component is crafted to behave like actual glass — refracting, reflecting, morphing.

01
Real Refraction
Layered gradients, inner shadows, and specular highlights simulate actual glass optics.
02
Iridescent Color
Animated gradient backgrounds shift in hue, mimicking thin-film light interference.
03
Organic Morphing
Blob shapes continuously morph with smooth border-radius animation — alive, never static.
04
Zero Dependencies
Pure CSS & vanilla JS. No frameworks, no bloat. Drop it in any stack.
05
Spring Physics
Every transition uses cubic-bezier spring curves for that satisfying over-shoot feel.
06
Fully Accessible
WCAG 2.1 AA compliant. Focus states. Keyboard navigable. Screen reader friendly.
