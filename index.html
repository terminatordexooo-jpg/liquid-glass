Iridescent Chrome

03
Organic Morphing
Simplex noise vertex displacement in vertex shader. Alive, never static.
04
Spring Physics
Every interaction uses cubic-bezier spring curves for tactile, satisfying feel.
05
Zero Dependencies
Pure CSS + vanilla JS components. Three.js only for the hero. Drop it anywhere.

WCAG Accessible
